Penjelasan :
jadi pada program saya ini hanya terdapat satu file class dan satu main yang terdiri dari file Resepsionis dan Main. disini alur program yang saya buat ialah proses pemesanan atau proses booking tiket bioskop.
program ini menggunakan arraylist untuk menyimpan data dari inputan user.
Pada file cpp, java, dan python, user disajikan dengan sebuah tampilan menu yang bisa dipilih sesuai dengan kemauan user.
User dapat memilih opsi yang tersedia mulai dari opsi 1 sampai 6. Dikarenakan penyimpanan data hasil inputan tidak memakai notepad atau penyimpanan database lainnya,
jadi hanya menggunakan perulangan do while yang akan berhenti pada saat user memasukkan nomor 6 sebagai indikasi untuk keluar dari program.

atribut yang ada pada class masing2 bahasa terdiri dari:
1. Nomor tiket
2. Tanggal nonton
3. Nomor studio
4. Nama film

kalau user menginput angka 1, maka user akan dibawa ke menu booking tiket atau menambah data.
kalau User menginput angka 2, maka user akan dibawa ke manu display tiket yang akan menampilkan semua data tiket yang telah di booking.
kalau user menginput angka 3, maka user akan dibawa ke manu update tiket. proses update ini dimulai dengan user menginput nomor tiket yang akan di update
kemudian program akan melakukkan search ke seluruh data tiket yang ada dan kalau ketemu maka user dapat melakukkan update.
kalau user menginput angka 4, maka user masuk ke menu hapus tiket yang prosesnya kurang lebih sama dengan proses update yaitu dengan cara nomor tiket dicari terlebih dahulu kemudian dihapus.
kalau user menginput angka 5, maka user masuk ke menu cari tiket.
kalau user menginput angka 6, maka user keluar dari program.
